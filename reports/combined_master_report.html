🌟 Abstract

Reading, analyzing, and organizing academic research papers is one of the most time-consuming tasks for graduate students, researchers, and engineers. When preparing a thesis or literature survey, students usually have to juggle multiple disconnected tools: reference managers like Mendeley or Zotero to keep track of citations, PDF readers to read dense papers, ChatGPT or Claude to explain hard concepts, and spreadsheets to manually compare different authors' methodologies.

To solve these practical problems in a single unified system, ScholarPulse AI Studio was developed. It is a full-stack web platform built with Django REST Framework (DRF) on the backend, React 18 and Tailwind CSS on the frontend, ChromaDB for local vector similarity search, and Google Gemini for generative AI tasks.

⚡ 14 Core Research Modules Architecture

1. DOI / ArXiv Ingestion CrossRef & arXiv XML APIs auto-import papers and metadata into ChromaDB.
2. Mendeley Citation Hub 7 academic formats (APA, IEEE, Harvard, MLA, Chicago, BibTeX, RIS) with 1-click downloads.
3. Cross-Paper Matrix Literature review comparison table with RFC-4180 CSV export.
4. ScholarCast Podcast Dual-host dialogue synthesis with browser speech playback, speed controls, and waveforms.
5. Reviewer #2 Rigor Roast Rigor Score (0–100), methodology critique, and viva defense directives.
6. Formula to PyTorch Code LaTeX equations converted to runnable PyTorch code with Big-O complexity bounds.
7. Semantic RAG Copilot Grounded Q&A using ChromaDB cosine similarity retrieval.
8. 4-Level Explain Engine Adapts explanations for Beginner, Undergrad, MCA Engineer, and Scholar.
